# WoWpoPolsku-Quests

Fork addonu WoWpoPolsku-Quests dla WotLK w wersji 3.3.5.

Kod źródłowy pochodzi z oficjalnej strony projektu:
https://wowpopolsku.pl/pobierz

# Poprawione błędy / dodane funkcjonalności

* naprawienie wyświetlania oryginalnego tekstu w Quest Logu po wciśnięciu przycisku QTR
* naprawienie błędu braku tłumaczenia w Quest Details po otwarciu za pomocą linku w liście bieżących zadań przy pierwszym logowaniu
* dodanie tłumaczenia przy otwarciu Quest Details za pomocą linku w liście bieżacych zadań (pod mapą)
* dodanie tłumaczenia przy powiększeniu mapy za pomocą przycisku WorldMapFrameSizeUpButton
* dodanie tłumaczenia przy otwarciu mapy za pomocą przycisków w liście bieżących zadań (pod mapą)
* dodanie tłumaczenia przy otwarciu mapy z poziomu QuestLoga za pomocą przycisku QuestLogFrameShowMapButton
* dodanie lokalizacji do przycisków nawigacyjnych w tutorialu
